# WebGPU smiley face

A tiny, readable WebGPU example that draws a friendly smiley from generated triangle geometry. It includes responsive high-DPI rendering and an accessible compatibility state for browsers without WebGPU.

```sh
corepack pnpm install --frozen-lockfile
corepack pnpm dev
```

Quality gates:

```sh
corepack pnpm lint
corepack pnpm typecheck
corepack pnpm test
corepack pnpm build
```
A reproducible browser-first WebGPU smiley face built through Difly
